## §1 语境

- **给谁用**：订单管理员（桌面）、销售主管（看报表）
- **最重要的决策**：今天哪些订单卡在审核、哪些要延期
- **使用场合**：桌面浏览器，1440 宽为主
- **非目标（已确认）**：真实登录与权限、后端校验、导出 Excel、国际化、暗色模式、真机适配
- **验收口径**（Q9）：发起人验收 · 逐页演示 + 断网双击 · 页面清单全通且主流程可点 · 2 轮返工 × ≤5 处 · 交付静态站 + README + 截图 + SPEC（不含 PDF）

## §2 规范

| 旋钮 | 取值 | 理由 |
| --- | --- | --- |
| 对比强度 | 中 | 常规后台，正文与辅助需拉开 |
| 信息密度 | 中（行高 44） | 一屏 12–14 行可扫读 |
| 圆角与柔软度 | 中（8px） | 中性，不暗示行业 |
| 色温与色彩面积 | 冷 · 强调 ≤2% | 只给主操作与当前态 |
| 动效幅度 | 低（150ms） | 减少干扰 |

- 字体：系统栈（离线演示，不引 Web 字体）；标题 600 / 正文 400，标题字距 −0.01em，数字 tabular-nums
- 色板：冷灰底 #F1F3F6 · 卡片 #FFFFFF · 钢蓝 #2563EB · 墨 #111827

## §4 已知限制

1. 数据为演示构造，无真实接口；
2. 未实现权限与角色切换；
3. 单页图表为静态示意，不含交互联动；
4. 手机端仅保证不溢出，未做专门布局。
