# 配色面积预算（吸收自「8 种高级审美 Dashboard」）

> 读时机：步骤 2.5 定旋钮、步骤 5.5 评审。核心思想：**风格 = 面积配比，不是色相本身**。
> 同一组颜色，面积比例不同就是两种气质；配比可量化，也可被 G8 的 `accent_ratio` 粗略验证。

## 八种配比（底 : 墨/中性 : 强调）

| 风格 | 配比 | 做法 | 适用 |
| --- | --- | --- | --- |
| 大色块分区 | 深底 60% + 4 块高饱和 30% + 中性 10% | 一整块深底，四块高饱和色浮在上面，每块代表一类内容 | 数据门户、会议大屏 |
| 图片卡片流 | 中性 70% + 真实图片 28% + 强调 2% | 彩色全部来自内容图片，界面本身几乎不上色，只留一支强调给当前态 | 内容型产品、素材库 |
| 玻璃拟态 | 渐变底 55% + 半透白 40% + 重色 5%（≤2 处） | 淡蓝紫渐变底 + 半透明白卡；重色只给主操作与当前项 | 科技产品、AI 工具 |
| 高密度卡片墙 | 浅色底 60% + 白卡 35% + 强调 5% | 淡色底 + 白卡浮起；强调色只用于当前态，另起一套小色标 | 管理后台、监控 |
| 荧光点睛（暗） | 近黑 80% + 墨黑 12% + 荧光 1–2% | 唯一的高饱和只出现在「要你看的那一处」 | 开发者工具、终端 |
| 杂志排版 | 淡灰蓝 44% + 近白 50% + 高饱和 1.6% | 大面积中性 + 极小面积高饱和；靠字体与留白立风格 | 报告、内容站 |
| 深色压顶 | 顶部深色 37% + 奶油底 55% + 暖橘 3% | 深色只压顶部一条，其余浅底；一支暖色做记忆点 | 仪表盘、官网后台 |
| 暗色控制台 | 深底 95% + 强调 1.4% | 底占九成五，强调只给可操作处；靠明度分层而非彩色 | 运维、控制台 |

## 怎么用

1. 先定「底占多少」——底决定气质（95% 深=控制台，50% 浅=杂志），再定强调面积（1–3% 最稳，>10% 变成营销页）。
2. 强调色面积 = 主按钮 + 当前选中 + 关键状态点；**不要给次要按钮上色**。
3. 与家族的关系：家族给色相家族，本节给面积预算；同一家族可换配比得到不同气质。
4. G8 的 `accent_ratio` 是粗验：后台常态 0.2–2%，超过 5% 要问「是不是每个按钮都上色了」。

## 反例阈值

- 强调面积 >10%：页面变成海报，长时间使用疲劳；
- 深色底 <90% 的「暗色控制台」：分层不成立，卡片会浮不起来；
- 图片流里界面自己上色：图片与界面抢注意力，两边都不成立。
