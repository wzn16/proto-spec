# 台账页模式（Ledger）· 变体菜单

> 读取时机：生成任何列表/台账/清单页之前。这是**参考基线**，不是标准答案；按项目语境偏离时在 SPEC 写明理由即可。
> 先按语境选形态与参数，把选择与理由写进 SPEC，再装配。

## 一、选形态（4 种，按业务结构选）

| 形态 | 结构 | 适用 | 不适用 |
| --- | --- | --- | --- |
| A 标准台账 | 页头 → KPI(0–4) → 筛选 → 工具栏 → 表格 → 分页 | 单据类（订单/工单/任务），字段 6–14 | 层级强关联数据 |
| B 主从台账 | 左树/左列表（280–340）+ 右表 | 有层级或分类导航（产品树/组织/目录） | 单层扁平数据 |
| C 卡片台账 | 卡片列表（1–4 列）或列表行卡 | 运营看板、审批待办、需要缩略图/进度的场景 | 列 >8 的数据对比 |
| D 高密度数据台账 | 无 KPI、紧凑行、冻结首列与操作列、列显示设置 | 审计/对账/导出型重度使用 | 面向非专业用户 |

## 二、可调维度（每项都写进 SPEC，不写则用「默认」）

| 维度 | 选项 | 默认 | 选择判据 |
| --- | --- | --- | --- |
| 密度 | `--dense` 36 / 标准 44 / `--comfort` 52 | 标准 44 | 审计对账选密集，触屏/年长用户选舒适 |
| 斑马纹 | `--zebra` 开 / 关 | 关 | 列 >10 且无分组时开，帮助横向追行 |
| 行选中 | 浅底 + 左条 / 仅复选 / 仅高亮 | 浅底+左条 | 批量操作为主时用足；只读列表仅高亮 |
| 操作列 | 文字按钮 ≤3 / 图标 / 「更多」菜单 | 文字 ≤3 | 操作 >3 用更多菜单；空间紧用图标 |
| 分页 | 页码分页 / 加载更多 / 虚拟滚动 | 页码分页 | 大数据量后台用加载更多；>5000 行用虚拟滚动 |
| KPI | 0 / 2 / 4 / 6 张 | 4（有汇总诉求时） | 纯录入型台账可 0 张 |
| 筛选 | 常驻 / 抽屉 / 弹层 / 无 | ≤4 字段常驻 | >4 字段进抽屉；条件单一可省筛选区 |
| 空态 | 三态齐全 / 仅无数据 | 三态齐全 | 数据源必有时可只做无数据 |

## 三、表格内部（可调，非固定）

- 编码列：等宽（推荐）/ 常规 —— 编码是识别主键时用等宽。
- 金额/数量：右对齐等宽 / 左对齐 —— 需要竖向比大小时右对齐。
- 状态：圆点+文字 / 徽标 / 纯文字 —— 状态种类 >5 时用纯文字+色点，避免色彩过载。
- 主键列是否冻结：是（横向滚动 >8 列时）/ 否。
- 列宽：给最小宽度，允许 `列设置` 调整；不硬编码固定像素到骨架里。

## 四、可用性底线（建议不破；破要写理由）

1. 表头粘顶；行可辨识（hover 或斑马二选一，必须有其一）。
2. 每列有明确对齐规则；数字右对齐，文字左对齐。
3. 分页必须显示总数；每页条数可选。
4. 无数据与无结果分开表达，且都给出下一步动作。
5. 单行主操作 ≤3 个可见；破坏性操作需二次确认。
6. 批量操作在选中后出现，并能一键取消选择。
7. 对比度达标（正文 ≥4.5:1），状态色不单独承担信息（必须配文字）。
