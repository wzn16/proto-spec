# 台账页模式（Ledger）

> 读取时机：步骤 4 生成任何「列表/台账/清单」页之前。骨架顺序不可调换。

## 一、骨架

```
页头：标题(20/600) + 右侧唯一主操作
KPI 行（可选，≤4）：标签 12 灰 + 数字 20 半粗等宽
筛选区：≤4 字段 → 常驻 `c-qbar`；>4 字段 → 工具栏「筛选」按钮 + `c-chips` 条件回显
工具栏 `c-toolbar`：左＝批量操作（选中浮出 `c-bulkbar`）｜右＝刷新/密度/列设置/导出
表格 `c-data-table` → 分页 `c-pager`
```

## 二、表格规格

| 维度 | 规则 |
| --- | --- |
| 列宽 | 序号 56 · 复选 44 · 编码 130–170 · 名称自适应 · 操作固定右侧 `c-data-table__actions` |
| 排版 | 编码列等宽 12 次级灰（`__code`）；名称 13 主文字；金额/数量右对齐等宽 |
| 状态 | 圆点 + 文字（`c-tag c-tag--dot`），禁忌整块纯色 |
| 行高 | 44 标准 / 36 紧凑；表头 38 粘顶 12px + .02em 字距 |
| 分隔 | 行底 1px + hover 浅底；**不用斑马纹** |
| 选中 | 行浅蓝底 + 左 2px 主色条，复选同步，批量条浮出 |
| 分组 | `c-data-table__group`（34 高，浅灰底，维度名 + 值） |

## 三、三种空态（不可混用）

- 无数据（首次）：`c-empty` + 主操作按钮
- 无结果（筛选导致）：`c-empty--compact` + 「清空筛选」，不给主操作
- 加载：5 行 `c-skeleton` 保持列宽，≥300ms 才出现
- 错误：区域级「重试」，不要只 toast

## 四、反模式

卡片套卡片 · 每格加底色 · 表头用主色 · 分页只给上下页 · 筛选无回显 · 单行 5+ 操作按钮 · 每页条数不可选。
