# 视觉评分单（G7 强制门）

> 读时机：**每轮页面完成后立刻**，交付前复查。产出物：`<项目>/qa/visual-review.md`。
> 这不是自我表扬文档；每项必须写证据（位置 + 现象），分数 <4 必须改，改不了要写原因。

## 一、三秒测试（最先做，写两句）

把首屏缩到 480px 宽看三秒，写下：
- `像哪一年的哪一类产品：……`
- `第一眼看到的是：……`
- 判定：像组件库默认样式 / 若干年前通用产品 → **总分上限 7**

## 二、锚线检查（写数字，不写形容词）

- 页面上所有标题与正文块的**左边缘**归到几条垂直锚线？（理想 2–3 条）
- 若有 4 条以上，逐条列出是哪几块没归位。
