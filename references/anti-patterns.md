# 反例图集（为什么错）

> 读时机：步骤 5 自检、步骤 5.5 评审、或用户说"这样不行"时对照。
> 图：`references/anti-patterns/rule-violations.png`（10 个真反例，每条标注对应 `detail-rules.md` 的编号与正确做法）。
> 注意：该图**故意包含违规**（重叠卡片、低对比胶囊等），对它跑 lint 会报警——这是预期，不是缺陷。

## 图集覆盖的 10 条

| 图内编号 | 规则 | 症状 | 正确做法 |
| --- | --- | --- | --- |
| #2 | 卡片内表格 | 表格宽于卡片，右侧被裁或压边框 | 满宽 + 名称列换行 + 编码列 ellipsis |
| #3 | 表格限宽 | 表格缩左、右侧空白、锚线断 | 用列宽档位，不用 max-width |
| #10 | 动作重复 | 页头/卡片头/空态各一个「新增」 | 一屏只出现一次主操作 |
| #14 #15 | KPI 语义 | 字段数/层级数/数据集，且无对比基准 | 可决策指标 + 环比/目标 |
| #17 | 数字口径 | 1,786 / 1786 / 2323 混写 | ≥1000 千分位，全站一致 |
| #19 | 按钮文案 | 确定 / 提交 / Do | 保存草稿 / 提交审核 / 发送周报 |
| #20 | 填充文字 | 示例 / 待核实 / 仅供演示 | 删掉或换真实业务内容 |
| #25 | 缺空态 | 表格无数据时只剩空白 | 三态：无数据给主操作 / 无结果给清空 / 加载骨架 |
| #13 | 行内动作过多 | 每行五个文字按钮 | ≤3，其余进「更多」 |
| #26 | 视觉噪音 | 斑马纹 + 满屏彩色胶囊 | hover + 行线；状态用圆点+文字 |

## 怎么用这张图

1. **评审前**：先扫一遍图集，再打开自己的页面，通常能自救 3–5 处。
2. **被用户指出问题时**：在图集里找对应条目，改法直接照「正确做法」那一行。
3. **补充反例**：新发现的违规，先写进 `detail-rules.md` 的编号，再画一个 320px 的块加进 `index.html`，重截 `rule-violations.png`。
