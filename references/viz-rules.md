# 数据可视化规则（Dashboard / 图表 / KPI）

> 读时机：步骤 4 写概览页、分析页、任何含图表的页面之前。

## 一、仪表盘的"决策故事"

- 一屏只回答 **1–2 个决策**（如"本周哪些产线异常上升"），不是把所有指标摊开。
- KPI 带 ≤4 张；主指标占 2 栏或加描边，其余降为次级（16px + 次级色）。
- 每个 KPI 必须带**对比基准**（环比/目标/上期），只有绝对值的指标是数字墙。
- 每个 KPI 可下钻到明细（点击 → 台账/抽屉）。

## 二、图表选择

| 数据形态 | 用什么 | 不要用 |
| --- | --- | --- |
| 单系列时间趋势 | 折线 / 面积（≤1 系列面积） | 双 Y 轴、3D |
| 类别对比（≤7） | 竖向条形 | 饼图 |
| 类别对比（>7） | 横向条形（按值排序） | 圆环图配图例 |
| 占比（≤5 且差 >2 倍） | 单环图 + 直接标注 | 多环饼图 |
| 分布 | 直方图 / 箱线 | 平均值的柱状撒谎 |
| 关系 | 散点（>50 点时加透明度） | 折线连散点 |
| 单一数值 vs 目标 | 子弹图 / 进度条 | 仪表盘指针 |

## 三、数据墨水比（Tufte）

- 删掉：装饰性网格线、卡片边框叠阴影、背景渐变、无意义的图标、重复的图例。
- 网格线只保留最浅一档（`--s-border`），横向优先，纵向可省。
- 坐标轴标签取整（3.5M 而不是 3,487,212）；单位写一次（轴标题或首个标签）。
- 对齐：数值右对齐、等宽数字；类别左对齐。

## 四、配色

- 数据色 ≤2 个系列 + 中性灰作对照；超出用同一色相的明度阶梯，不要凑彩虹。
- 语义色优先：异常红、正常绿、警示琥珀；色盲安全（红绿同时用形状/文字区分）。
- 强调只给"要点"：一条趋势线、一个异常柱，其余灰。

## 五、拒绝的常见做法

- 一屏 8 个图表，每个都 200px 高；
- 饼图超过 5 片；
- 双 Y 轴把两个不相关指标叠在一起；
- 图表标题重复轴标题；
- 图例放右侧竖排占 1/3 宽度（类别少时直接标注在线上）；
- 用 3D、阴影、渐变做"高级感"。
