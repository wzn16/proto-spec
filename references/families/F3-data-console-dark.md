## ① 调性

深色玻璃舱里的专业冷静，数字是唯一主角。所有界面元素退成深浅不同的「舱壁」，把亮度留给数据本身。打开任何一页：像坐进交易台或卫星控制室——安静、致密、精确。

## ③ 组件风格规则（family.css 承载项加 ◆）

- 按钮：主=亮蓝实底深底字（#0F1117，5.9:1 ✓）；次=透明底 1px 深描边浅字；hover 变亮不变暗（暗色交互铁律，family.css 不需处理——值在 tokens）。
- 卡片：深底 + 1px 深描边，无阴影；卡片标题用 --s-text-secondary 小号大写敏感性中文化处理（中文无大写 → 用字距 0.05em + 12px）。
- 表格：◆斑马纹启用（偶数行提亮至 #181C26，nth-child 实现）；数字列强制 u-num 等宽右对齐；涨跌 delta 用 success/error 高饱和（暗底上才立得住）。
- 侧栏导航：◆深底侧栏（非白！与页底同层，右缘 1px 分隔）；选中 = soft 蓝底 + 亮蓝字。
- 图表区：分类色只用 --g-chart-1..6，禁现场吸色；单图系列 ≤6。
- 动效：数字滚动、行 hover 十字定位属精修层职责；过渡 150–250ms。

## ④ 适用 / 不适用场景

- 适用：监控大屏、BI 报表、运维可观测后台、数据产品演示、含图表密集页的原型。
- 不适用：表单录入密集型后台（暗底长表单疲劳度高）、政务/医疗正式汇报、需要打印交付的原型（打印全黑是硬伤——访谈时作为「代价」明示）。

## ⑤ 身份特征与禁忌

- 身份特征：深底三阶表面（页/卡/hover 逐级提亮）、亮蓝主色、高饱和分类色板、紧凑行高。
- 禁忌：①大面积纯白卡片/白底控件混入（破坏表面阶层）；②hover 用加深处理（暗色系 hover 必须变亮）；③低饱和灰彩图表（分类色板是家族给定的，不许自制莫兰迪）；④阴影当主要分层手段（只准表面提亮 + 描边）。
- 校验记录：#E6E9EF/#0F1117 = 15.5:1；#8B93A5 = 6.1:1；#4C8DFF = 5.9:1；语义三色 6.8–11.3:1；主按钮 #0F1117/#4C8DFF = 5.9:1。
