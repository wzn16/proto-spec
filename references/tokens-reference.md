# tokens 与类名规则（防跑偏手册）

> 上级入口：SKILL.md 步骤 4。唯一事实源是项目内 `assets/tokens.css`；本文件讲使用规则。

## 三层变量

| 层 | 前缀 | 内容 | 页面可否直接使用 |
| --- | --- | --- | --- |
| L0 基元 | `--g-*` | 原始色阶、字号、圆角、阴影原始值 | 禁止，仅 tokens.css 内部引用 |
| L1 语义 | `--s-*` | 按用途命名：色彩 / 排版 / 间距 / 圆角 / 阴影 | 页面与组件统一用这层 |
| L2 组件 | `--c-*` | 按钮高、输入高、表格行高、侧栏宽、顶栏高等几何 | 可用（通常无需直接用） |

排版不散用三个变量：优先使用 `base.css` 的组合工具类（如 `.u-text-title` 一次锁定字号 + 行高 + 字重），
避免逐页自由组合导致字阶漂移。

## 类名命名空间（四前缀）

| 前缀 | 含义 | 页面可否改动 |
| --- | --- | --- |
| `c-` | 组件（来自 snippets 片段库） | 禁改实现；只用类名 + 变体 |
| `l-` | 布局（模板内置结构） | 禁改；按模板插槽填内容 |
| `u-` | 工具类（base.css 白名单） | 只用白名单内的，不新造 |
| `p-` | 页面局部样式 | 唯一出口：仅限使用 tokens 变量，≤30 行，超限说明该抽组件回库 |

## 生成页面的取值规则（G1 检查口径）

1. 颜色：只许 `var(--s-*)` / `var(--c-*)`；页面出现 `#hex`、`rgb()` 即违规。
2. 间距：`padding/margin/gap` 只允许 `--s-space-1..8` 与 `--s-gap-*` 的值档（4/8/12/16/20/24/32/48px）。
3. 字号：只允许 tokens 定义档位（12/13/14/16/20/24/30px）。
4. 圆角：只允许 `--s-radius-*` 档位（6/8/12/9999px）。
5. 结构性例外（不算违规）：`0`、`1px`（边框宽）、`100%`、`50%`（正圆）、`auto`、`none`、`transparent`、`currentColor`。
6. `calc()` 默认禁止；页面内自定义 CSS 变量（`:root { --x: ... }`）禁止；引用未定义变量禁止。
7. 页面局部 `<style>` 只写 `p-` 前缀类，且全部取值来自 tokens 变量。

## 片段复制纪律

- 片段 = HTML 注释头（用途/变体/可改范围）+ 可直接展开的结构。生成页面时**复制展开为真实 HTML**（构建期复制，非运行时 include，file:// 下运行时抓取会被浏览器拦截）。
- 复制后只允许：改文字内容、增删重复单元（表格行/列表项/表单项）；禁改 class 结构、禁加内联样式。
- 新需求先问「现有组件能否组合」；确实没有才新建片段文件入库（snippets/ + catalog 登记），再在页面使用。
