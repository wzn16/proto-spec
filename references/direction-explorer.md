# 方向对比页（Direction Explorer）

> 读时机：出完 2–3 个方向后。把方向做成可并排比较的页面，而不是让用户看三张散图。

## 一、做法

1. 每个方向产出一张**首屏同内容**的样页（同一份数据、同一屏尺寸），只换骨架/字体/色彩/控件语法。
   - 存到 `explore/<方向id>.html`；
   - 首屏一轮每方向只截一张，不做全套取证。
2. 生成对比页：把候选清单交给 `oil_ui_explorer`（manifest 含 id / 名称 / 概念 / 字体 / 特征 / 色板 / 源路径 / 视口），
   得到 `style-explorer.html`，含并排预览、方向信息卡与选择记录。
3. 交给用户选：一次给三个，附一句话取舍（每个方向多花什么代价、少得到什么）。
4. 选定后：把该方向卡写进 SPEC，其余方向归档到 `explore/`，不作为交付物。

## 二、候选清单要点

| 字段 | 要求 |
| --- | --- |
| id / 名称 | 稳定、可引用（如 `d1-density`） |
| 概念 | 一句话：这个方向主张什么 |
| 字体 | 具体字族与尺度关系，不写"现代感" |
| 特征 | 3–4 条可观察特征（不是形容词） |
| 色板 | 3–5 个十六进制 |
| 源 | `explore/d1.html` 相对路径 |
| 视口 | 原型统一 1440×900 |

## 三、禁忌

- 三个方向都用同一骨架只换颜色（等于一个方向）。
- 把对比页当交付物给甲方（它内部工具）。
- 用不同数据让方向显得不同（必须同内容比）。
