# 参考图 → 设计规范（Reference to Spec）

> 读时机：用户给了参考图/截图/竞品、"我想要这种感觉"时（对应 Skill 榜里的 reference-design-contract）。

## 一、从参考图里量什么（不靠眼看）

| 项 | 怎么量 | 产出 |
| --- | --- | --- |
| 底色 / 卡片底 | 取大面积区域的中位色（避开文字与图片） | `--s-bg-page` / `--s-bg-card` |
| 强调色 | 取饱和度最高、面积最小的色块；统计其面积占比 | `--s-color-primary` + 面积预算 |
| 中性文字 | 取正文像素的众数色；辅助文字取更浅一档 | `--s-text-primary` / `--s-text-secondary` |
| 边框 | 取卡片边缘 1px 线的颜色；若无线则记「无边框」 | `--s-border` |
| 圆角 | 量卡片四角弧长（像素） | `--g-radius-*` |
| 间距节奏 | 量相邻块的间隙集合，取出现频次最高的 3 个值 | `--s-space-*` 档位映射 |
| 字阶 | 量标题/正文/辅助的行高像素 | `--s-fs-*` 档位映射 |
| 阴影 | 若卡片有投影，量偏移与模糊半径 | `--s-shadow-*` |

## 二、流程

1. **取色** → 3–5 个主色值（底、卡、强调、文字、线）。
2. **对号** → 与 `family-library.md` 的十家族比对：色相与面积最接近的家族 = 候选；若接近但没有完全对上，允许"家族 + 自由变量覆盖"，但**不得覆盖身份特征**。
3. **落 SPEC** → 把量到的值写进 SPEC §2；面积预算写进 §2.1。
4. **反写差异** → 明确写出「我们与参考图不同的三处及原因」（通常是密度、字阶、交互容器）。

## 三、可信度规则

- 参考图是 2 倍图时要除以 2 再换算像素；
- 只从一个截图推不出交互动效——动效必须写"未观察到，按家族默认"；
- 不要照抄参考图的品牌资产（logo、插画、专有图标）；
- 参考图与客户品牌冲突时，以客户品牌为准，参考图只借"面积与节奏"。

## 四、输出给谁

产出物是 **SPEC 片段**，不是"像不像"的评语。评审用 `visual-scorecard.md` 的锚线与六维，
比对时用同视口截图并排，不凭记忆。
