# 表单模式（Form）· 变体菜单

> 读取时机：生成任何表单/抽屉/弹窗之前。容器与参数都是**参考基线**，可按语境换，写清理由即可。

## 一、选容器（5 种）

| 容器 | 尺寸 | 适用 | 代价 |
| --- | --- | --- | --- |
| 抽屉 `c-drawer--sm/md/lg` | 420 / 560 / 720 | 从台账进入、字段 ≤8、需保留列表上下文 | 长表单滚动多 |
| 独立页 | 全页（内容宽 ≤960） | 字段 9–20、需分组导航、可分享 URL | 丢失列表上下文 |
| 分步表单 | 全页 / 抽屉 | >20 字段或业务本身分段（申请→审批→归档） | 步骤 ≤4，需可回退 |
| 弹窗 `c-modal` | 480（宽 640 仅限表格选择） | 确认、改状态、单字段、≤4 字段 | 不承载复杂表单 |
| 内嵌子表 | 主表单内区块 | 主子表（明细行） | 需独立的新增/删除行交互 |

## 二、可调维度

| 维度 | 选项 | 默认 | 判据 |
| --- | --- | --- | --- |
| 栅格 | 1 列 / 2 列 / 3 列 | 2 列 | 字段短且多→3；长文本/年长用户→1 |
| 标签位置 | 上 / 左（120px） | 上 | 字段名长、表单密集时用左 |
| 控件高度 | 32 / 36 / 40 | 36 | 与台账密度保持一致 |
| 校验时机 | 提交时 / 失焦时 / 实时 | 提交时（+失焦补） | 金融/编码类字段可失焦即校验 |
| 保存策略 | 仅提交 / 手动草稿 / 自动草稿 | 手动草稿（>15 字段时） | 长表单必须可恢复 |
| 分组 | 无 / 分节标题 / 分步 | 分节（>8 字段） | — |
| 帮助信息 | 常显 / 图标悬浮 / 无 | 常显（关键字段） | 悬浮不可用于必填规则 |
| 联动 | 隐藏 / 禁用+说明 | 强依赖隐藏、弱依赖禁用 | — |

## 三、可用性底线（建议不破；破要写理由）

1. 必填有标记（红色 `*` 或「必填」文字二选一，全站统一）。
2. 错误显示在字段旁或字段下，并聚焦/滚动到首个错误；不得只弹 toast。
3. 提交按钮有 loading 与防重复提交。
4. 脏数据离开需确认或自动保留草稿。
5. 只读态可读（浅底 + 正常字色），不用灰到看不清。
6. 底部操作条在长表单中粘底或每段末尾重复。
7. 危险操作与提交物理分开（不同侧或加分隔），且二次确认。
