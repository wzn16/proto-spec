# 表单模式（Form）

> 读取时机：步骤 4 生成任何表单/抽屉/弹窗之前。**先定容器，再画字段**。

## 一、容器判据

| 场景 | 容器 |
| --- | --- |
| ≤8 字段且从台账进入 | 抽屉 720（`c-drawer`） |
| 9–20 字段 | 独立页 |
| >20 或分步业务 | 分步表单（≤4 步，可回退） |
| 轻量确认 / 改状态 | 弹窗 480（`c-modal`） |

禁止：台账页内平铺表单；弹窗承载 >8 字段。

## 二、栅格与字段

- `c-form-grid` 默认两列（320–360/列）；短字段可 `--3`；长文本/富文本 `c-field--full` 整行。
- 分组 `c-form-section`：标题 14/600，组间距 24，每组 ≤8 字段。
- 标签在上（12 次级灰），控件 32 紧凑 / 36 标准。
- 必填：标签后红色 `*`（`c-field--required`），不写「必填」二字。
- 帮助文本 12 灰在控件下（`c-field__hint`）；不使用 title 悬浮。
- 错误：字段下 12 红 + 控件描边转红；提交只标首个错误并滚动到位，顶部给汇总。
- 只读：浅底 + 无边框，不用禁用灰字。
- 联动：强依赖隐藏、弱依赖禁用并解释；异步选择走选择器弹窗（搜索 + 已选计数）。
- 脏数据：关闭前确认（存草稿 / 放弃 / 继续编辑）。

## 三、底部操作条 `c-form-footer`

粘底右对齐：`取消`（描边）· `保存草稿`（文字）· `提交`（主色实底）。
提交中禁用 + loading + 防重复；成功 toast + 关闭 + 台账刷新。
危险操作（删除/作废）放左侧 `c-form-footer__danger`，与提交物理分开。

## 四、反模式

一列拉满 · 标签在左参差 · 校验只 toast 不标字段 · 按钮等宽等重 · 明细表塞进主表单 · 主按钮在左。
